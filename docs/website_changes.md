# RiceLENS website corrections

The website is named RiceLENS. Gene choices show matching aliases and source descriptions; an exact display-symbol match is prioritized without discarding shared aliases such as SD1 or GS3.

GWAS tables and plots distinguish verified FDR-adjusted statistics from unverified adjustment status using text, colors and shapes. Explicit IRGSP-1.0 reference labels and chromosome bounds are checked; original-study coordinate remapping is not independently verified. Published association records are not complete SNP-level summary statistics or a uniformly significant collection.

These corrections are independent of the expression integrations added in subsequent commits.
