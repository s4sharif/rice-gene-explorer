# Platform navigation

RICELens now uses Home, Locus and Genes, GWAS, Cell Expression, Homolog Search, Download, Tutorial and Contact Us. See [the GWAS layout notes](gwas_layout.md) for the current routes, shared selection, counts, exports and deliberate placeholders.

Start the local preview with `python3 -m backend.app --port 8772`. Open <http://127.0.0.1:8772/>. The legacy `/variation` route remains supported as Locus and Genes.
